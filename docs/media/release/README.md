# Release screenshot provenance

These 29 PNGs are direct screengrabs from the running Gooey preview in an isolated
Hyprland compositor. The only application content is the repository’s Notes and
Files fixtures. No personal desktop, user documents, credentials, or messages are
shown. The Style menu uses the actual Gooey menu entry generated by the deployment
runtime, with its checked state derived from the private profile’s activation.

- Tested payload: `0.1.0-dev-ba91a43d0d1b`.
- Application source: `7ffec4b`.
- Host: the reviewed Omarchy 4.0.3-1 snapshot; Quickshell 0.3.1.
- Capture: 2560×1600 output at scale 2 (1280×800 logical coordinates).
- Method: `grim` with regions supplied by the native controls or QML menu geometry.
- No icons are redrawn and no UI state is composited into the images.
- Individual icons include two logical pixels of surrounding frame; menus use
  their own card bounds. Full frames show the context of the icon rows.

`capture.json` records each final region, dimensions, and file hash. The bar’s
“GOOEY · DEV” label is part of the screenshot fixture, not installed Gooey branding.
The Quickshell app name is correct for these sample windows; installed windows
show their own resolved app names.

Reproduce with `GOOEY_TEST_HOST=/usr/share/omarchy ./dev/run release-capture` after
building and staging the reviewed payload. See [the capture workflow](../../DEVELOPMENT.md#capture-release-images).
